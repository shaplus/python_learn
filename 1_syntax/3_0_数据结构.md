数据结构概述
数据结构是用于存储和组织数据的方式，Python中内置了多种数据结构，每种都有其特定的用途和特点：

数据结构	        特点	                   示例
列表 (List)	        有序、可变、可重复	        [1, 2, 3, "a"]
元组 (Tuple)	    有序、不可变、可重复	    (1, 2, 3, "a")
字典 (Dictionary)	无序、可变、键值对、键唯一	{"name": "Alice", "age": 18}
集合 (Set)	        无序、可变、元素唯一	    {1, 2, 3, 4}

访问方式：
索引：通过索引访问列表、元组、集合中的元素。
键：通过键访问字典中的值。
成员测试：通过成员测试（如 in 或 not in）检查元素值是否在集合中存在。
成员测试：通过成员测试（in、not in）检查元素是否在集合中。

适用场景:
列表 (List): 存储有序元素，需要频繁修改。
元组 (Tuple): 存储不可变数据，作为字典键。
字典 (Dictionary): 存储键值对，需要通过键快速查找。
集合 (Set): 存储唯一元素，需要数学集合运算。
