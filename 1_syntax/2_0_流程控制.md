# 流程控制总结

## 一、条件语句

### 1. 基本 if 语句
```python
if 条件:
    # 条件为真时执行的代码
```

### 2. if-else 语句
```python
if 条件:
    # 条件为真时执行的代码
else:
    # 条件为假时执行的代码
```

### 3. if-elif-else 语句
```python
if 条件1:
    # 条件1为真时执行的代码
elif 条件2:
    # 条件2为真时执行的代码
else:
    # 所有条件都为假时执行的代码
```

### 4. 嵌套条件语句
条件语句可以嵌套使用，形成更复杂的逻辑判断。

## 二、循环语句

### 1. for 循环
```python
for 变量 in 可迭代对象:
    # 循环体代码
```
- 可迭代对象包括：列表、元组、字符串、字典、range()等

### 2. while 循环
```python
while 条件:
    # 循环体代码
```
- 注意：必须在循环体内修改条件变量，否则可能导致无限循环

### 3. 循环控制语句
- **break**：终止整个循环
- **continue**：跳过当前循环的剩余部分，开始下一次循环
- **pass**：占位，什么都不做

## 三、注意事项

1. **缩进**：Python通过缩进来区分代码块，同一代码块的缩进必须一致
2. **无限循环**：使用while循环时要确保条件最终会变为假，避免无限循环
3. **循环效率**：对于大型数据集，要注意循环的效率，尽量优化算法
4. **嵌套层次**：嵌套循环的层次不宜过深，否则会降低代码的可读性
5. **代码风格**：保持代码风格一致，使用适当的空行和注释提高可读性
