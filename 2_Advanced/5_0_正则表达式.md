# 正则表达式概述
1. 什么是正则表达式？
正则表达式（Regular Expression，简称 regex 或 regexp）是一种用于匹配字符串中字符组合的模式。它是由普通字符（如字母、数字）和特殊字符（如元字符）组成的字符串，用于描述匹配规则。

2. 正则表达式的作用
- 文本搜索：在大量文本中快速查找符合特定模式的内容
- 文本替换：替换符合特定模式的文本
- 数据验证：验证输入数据是否符合特定格式（如邮箱、手机号）
- 数据提取：从文本中提取特定信息（如URL、日期）

3. 正则表达式在Python中的应用
Python通过内置的re模块提供对正则表达式的支持，这是我们学习的重点。
