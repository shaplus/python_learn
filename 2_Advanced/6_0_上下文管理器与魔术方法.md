# 魔术方法（Magic Methods）
## 基本概念
魔术方法是Python中以双下划线开头和结尾的特殊方法，它们在特定情况下被自动调用，
用于实现对象的特殊行为。

## 常用魔术方法分类
1. 构造与初始化
    - __init__(self, ...)：初始化方法，在创建对象时调用
    - __new__(cls, ...)：创建对象的方法，在__init__之前调用
    - __del__(self)：析构方法，在对象被销毁时调用
2. 字符串表示
    - __str__(self)：返回对象的字符串表示，用于str()和print()
    - __repr__(self)：返回对象的官方字符串表示，用于repr()
    - __format__(self, format_spec)：用于格式化输出
3. 运算符重载
    - 算术运算符：__add__, __sub__, __mul__, __truediv__等
    - 比较运算符：__eq__, __ne__, __lt__, __gt__等
    - 赋值运算符：__iadd__, __isub__等
4. 容器相关
    - __len__(self)：返回容器长度，用于len()
    - __getitem__(self, key)：获取元素，用于obj[key]
    - __setitem__(self, key, value)：设置元素，用于obj[key] = value
    - __delitem__(self, key)：删除元素，用于del obj[key]
    - __iter__(self)：返回迭代器，用于for循环
    - __contains__(self, item)：检查元素是否存在，用于in运算符
5. 上下文管理
    - __enter__(self)：进入上下文管理器
    - __exit__(self, exc_type, exc_val, exc_tb)：退出上下文管理器
6. 其他常用魔术方法
    - __call__(self, ...)：使对象可调用，如obj()
    - __getattr__(self, name)：当访问不存在的属性时调用
    - __setattr__(self, name, value)：设置属性时调用
    - __getattribute__(self, name)：访问任何属性时调用
    - __dir__(self)：返回对象的属性列表，用于dir()

# 最佳实践与注意事项
## 上下文管理器最佳实践
1. 总是使用上下文管理器管理资源：如文件、网络连接、数据库连接等
2. 保持上下文管理器简单：每个上下文管理器只负责一种资源的管理
3. 正确处理异常：在__exit__方法中妥善处理异常
4. 使用contextlib简化实现：对于简单的上下文管理，使用装饰器方式更简洁

## 魔术方法最佳实践
1. 遵循Python约定：不要随意创建自定义魔术方法
2. 保持方法简洁：每个魔术方法只实现必要的功能
3. 考虑性能影响：某些魔术方法（如__getattribute__）会被频繁调用，应确保其高效运行
4. 提供有意义的实现：如__str__和__repr__应返回有用的信息

## 注意事项
1. 不要过度使用魔术方法：只在必要时实现
2. 注意魔术方法的调用顺序：如__new__在__init__之前调用
3. 避免无限递归：在__getattr__等方法中要小心
4. 测试边缘情况：确保魔术方法在各种情况下都能正确工作
